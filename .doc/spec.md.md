# MALEMI — Especificação do Site Institucional

## 1. Objetivo

Criar o novo site institucional da **MALEMI**, uma empresa de soluções em tecnologia, dados, automação e inteligência artificial.

O site deve transmitir:

- tecnologia;
- sofisticação;
- confiança;
- inovação;
- profissionalismo;
- visão de futuro.

A estética deve combinar **luxo + tecnologia**, com uma experiência visual moderna e premium, mas sem parecer exagerada ou artificial.

O objetivo principal do site é apresentar a MALEMI, explicar claramente seus produtos e transformar visitantes em potenciais clientes.

# 3. Conceito visual

## Direção artística

Criar uma interface:

**Dark / Luxury / Technology / Premium / Minimalista**

A primeira impressão deve ser de uma empresa de tecnologia moderna e confiável.

Referências conceituais:

- empresas de tecnologia premium;
- software B2B moderno;
- data/AI companies;
- dashboards sofisticados;
- arquitetura digital;
- estética futurista discreta.

Evitar aparência de:

- site genérico feito com template;
- landing page excessivamente colorida;
- startup infantil;
- excesso de elementos;
- excesso de animações;
- visual "hacker";
- neon exagerado;
- gradientes muito fortes;
- excesso de cards.

---

# 4. Identidade visual

## Fundo

Utilizar predominantemente:

- preto;
- quase preto;
- grafite;
- tons muito escuros.

O fundo deve criar profundidade sem deixar a interface pesada.

## Cores de destaque

Utilizar a identidade da MALEMI como referência:

- azul para representar tecnologia, confiança e estrutura;
- verde/turquesa para representar dados, inovação e crescimento.

O verde deve ser usado como **acento**, não como cor dominante.

Sugestão de referência:

- verde próximo de `#09CCA2`;
- branco para textos principais;
- cinza claro para textos secundários;
- azul profundo para elementos estruturais.

As cores devem ser refinadas de acordo com as skills de frontend design.

---

# 5. Tipografia

Utilizar uma tipografia moderna e sofisticada.

Hierarquia clara:

- títulos grandes e fortes;
- subtítulos objetivos;
- textos curtos;
- bastante espaço negativo;
- excelente legibilidade.

Evitar excesso de fontes diferentes.

Preferir uma família tipográfica principal e, se necessário, uma segunda apenas para elementos específicos.

# 7. Hero da Home

O Hero deve ser o elemento mais impactante da página.

Headline principal:

**A tecnologia certa, te levará a novas oportunidades!**

Criar uma composição visual sofisticada em torno dessa mensagem.

Possíveis elementos:

- linhas digitais;
- pontos conectados;
- formas geométricas;
- elementos abstratos relacionados a dados;
- movimento muito sutil;
- iluminação discreta;
- elementos que lembrem arquitetura de dados.

Não utilizar imagens genéricas de banco de imagens de pessoas trabalhando em computadores.

O visual deve parecer construído especificamente para a MALEMI.

CTA principal:

**Conheça nossas soluções**

CTA secundário:

**Fale com a MALEMI**

O site deve possuir navegação extremamente clara.

Header:

- Logo MALEMI
- Soluções
- Sobre
- Como trabalhamos
- Contato

CTA no header:

**Fale conosco**

No mobile:

- menu hamburger;
- navegação simples;
- CTA visível.

---

# 11. Animações

Utilizar animações com propósito.

Priorizar:

- entrada suave de elementos;
- microinterações;
- hover elegante;
- transições suaves;
- movimento sutil no Hero;
- efeitos de profundidade.

Evitar:

- animações constantes;
- elementos piscando;
- excesso de parallax;
- animações que prejudiquem performance;
- qualquer coisa que distraia do conteúdo.

A sensação deve ser de **tecnologia premium**, não de demonstração de efeitos.

---

# 12. Responsividade

O site deve funcionar perfeitamente em:

- desktop;
- notebook;
- tablet;
- celular.

A experiência mobile não deve ser apenas uma versão reduzida do desktop.

Reorganizar os elementos quando necessário para manter:

- legibilidade;
- hierarquia;
- espaçamento;
- facilidade de navegação.

---

# 13. SEO

Aplicar as boas práticas definidas pela skill `seo-fundamentals`.

Preparar:

- title;
- meta description;
- headings semânticos;
- estrutura correta de H1/H2/H3;
- Open Graph;
- favicon;
- sitemap quando aplicável;
- robots.txt quando aplicável;
- URLs amigáveis;
- dados estruturados quando fizer sentido.

O site deve ser preparado para futuras páginas de serviços e conteúdos.

---

# 14. Performance

Priorizar:

- carregamento rápido;
- imagens otimizadas;
- lazy loading quando apropriado;
- componentes eficientes;
- evitar bibliotecas desnecessárias;
- evitar animações pesadas;
- evitar dependências que não agreguem valor.

A estética premium não pode significar um site lento.

---

# 15. Arquitetura do projeto

Organizar o projeto de maneira escalável.

Separar adequadamente:

- páginas;
- componentes;
- seções;
- dados;
- estilos;
- assets;
- configurações.

Evitar colocar toda a página em um único componente gigante.

Utilizar componentes reutilizáveis.

A arquitetura deve permitir futuramente adicionar:

- novas páginas;
- novos produtos;
- blog;
- área de clientes;
- formulários;
- integrações;
- APIs;
- páginas específicas para cada solução.

---

# 16. Conteúdo

Não inventar informações sobre a empresa que não estejam definidas neste documento.

Quando uma informação comercial ainda não estiver definida, utilizar texto provisório claramente identificável ou estruturar o componente para receber o conteúdo posteriormente.

Não inventar:

- clientes;
- números de resultados;
- depoimentos;
- certificações;
- prêmios;
- parceiros;
- cases;
- estatísticas.

---

# 18. Importante: construir com qualidade, não apenas fazer funcionar

Antes de começar a codificar:

1. analisar este documento;
2. ler as skills relevantes;
3. analisar a estrutura atual do projeto;
4. identificar a stack utilizada;
5. planejar a arquitetura;
6. definir os componentes;
7. só então iniciar a implementação.

Durante a implementação:

- seguir clean code;
- manter componentes pequenos;
- reutilizar componentes;
- evitar duplicação;
- validar responsividade;
- validar acessibilidade;
- validar SEO;
- validar performance.

---

# 19. Resultado esperado

O resultado final deve parecer um **site real de uma empresa de tecnologia premium**, e não um exercício de curso.

A página deve transmitir imediatamente:

**MALEMI**
**Tecnologia + Dados + Automação + IA**

com uma estética:

**escura + sofisticada + tecnológica + moderna + profissional.**

A prioridade é criar uma base visual e técnica excelente para depois evoluir o site durante o curso.

Não tentar construir todas as funcionalidades futuras agora.

Primeiro criar uma **Home extremamente bem executada**, com arquitetura preparada para crescimento.
